# Cashier Bengkel Motor - motodoct

Aplikasi kasir untuk bengkel motor motodoct.

## Struktur Proyek

```
cashier-motodoct/
├── frontend/   → tampilan UI
├── backend/    → API & logika bisnis
└── README.md
```

## Cara Menjalankan

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Kolaborasi Tim

```bash
# Sebelum mulai kerja, selalu pull dulu
git pull origin develop

# Buat branch fitur baru
git checkout -b feature/nama-fitur

# Setelah selesai
git add .
git commit -m "feat: deskripsi fitur"
git push origin feature/nama-fitur
# Lalu buat Pull Request ke branch develop
```
