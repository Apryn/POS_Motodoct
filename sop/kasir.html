STANDARD OPERATING PROCEDURE (SOP) KASIR

SOP Pelayanan Kasir & Penjualan POS
Divisi: Front Office / Kasir (POS)
Tanggal Berlaku: 14 Juni 2026
Jumlah Karyawan: 1 Kasir Aktif
Tipe Dokumen: Panduan Operasional Resmi

1. Persiapan Awal Hari (Opening Shift)

  1. Nyalakan komputer kasir dan printer thermal struk belanja.
  2. Buka Google Chrome dan masuk ke sistem kasir Motodoct: https://motodoct.com.
  3. Periksa koneksi internet. Jika halaman tidak termuat, pastikan router WiFi menyala.
  4. Siapkan modal kas modal awal (uang kembalian) sebesar Rp 300.000 di dalam laci uang kasir.

2. Alur Pelayanan Transaksi Kasir

Langkah A: Input Data Pelanggan & Mekanik

  • Identifikasi Pelanggan: Tanyakan plat nomor motor pelanggan. Input plat nomor pada kolom Pelanggan.
    • Jika terdaftar sebagai Member, nama pelanggan akan otomatis terpilih.
    • Jika Bukan Member, klik tombol + Baru di sebelah kanan kolom Pelanggan untuk mendaftarkan Plat Nomor, Nama, dan No. HP secara cepat.
  • Pilih Mekanik: Jika transaksi melibatkan Jasa Servis, Anda wajib memilih mekanik aktif pada dropdown Mekanik untuk keperluan kalkulasi komisi servis. Jika hanya membeli sparepart biasa, mekanik bersifat opsional.

Langkah B: Pencarian & Input Produk ke Keranjang

  • Anda dapat menggunakan scanner barcode pada kolom pencarian untuk langsung memasukkan barang secara otomatis.
  • Jika input manual, ketik nama sparepart, kode barang, atau lokasi rak pada kolom pencarian.
  • Membaca Nama Lain (Alias): Jika pelanggan menanyakan nama alias/sinonim barang (contoh: "cover knalpot" untuk barang "ANTI PANAS KENALPOT"), Anda dapat melihatnya langsung pada text abu-abu miring di bawah nama barang utama.
  • Cek Harga Cepat (Tombol F2): Tekan tombol F2 pada keyboard kapan saja untuk membuka pop-up pencarian harga cepat, ketersediaan stok, dan posisi rak barang tanpa merusak isi keranjang belanja aktif.
⚠️ PENTING: Penyesuaian Harga Manual
Jika perlu menyesuaikan harga sparepart secara manual, klik ikon pensil ✏️ di samping harga barang pada keranjang belanja. Sistem akan meminta verifikasi password kasir Anda demi mencegah perubahan harga tidak sah.

Langkah C: Pembayaran (Payment Process)

Metode Pembayaran SOP Operasional Cara Verifikasi Keberhasilan
Tunai (Cash) Input nominal uang tunai yang diterima dari pembeli pada kolom Uang Diterima. Sistem akan menghitung kembalian. Pastikan nominal kembalian yang diserahkan ke pelanggan sudah sesuai angka Kembalian.
QRIS Statis/Dinamis Pilih metode QRIS. Tunjukkan layar monitor kepada pelanggan untuk discan. Minta pelanggan menunjukkan bukti transfer berhasil pada HP mereka sebelum menekan tombol BAYAR.
Transfer Bank Tunjukkan nomor rekening bank yang muncul di layar. Klik tombol Salin untuk menyalin no. rekening jika diperlukan. Lakukan cek saldo m-Banking bengkel untuk memastikan uang masuk sebelum mengizinkan pelanggan membawa pulang kendaraan.

Langkah D: Cetak Struk Belanja

  • Setelah menekan tombol BAYAR, pop-up Transaksi Berhasil akan muncul beserta struk belanja.
  • Klik Cetak Struk untuk mencetak struk belanja fisik melalui printer thermal, kemudian serahkan struk kepada pelanggan.

3. Fitur Pendukung Kasir

A. Fitur Rekam Medis (Medical Record Kendaraan)

Ketika Anda memasukkan plat nomor kendaraan yang sudah pernah servis di Motodoct, tombol Rekam Medis berwarna oranye akan muncul. Klik tombol tersebut untuk melihat:

  • Nama pemilik dan tanggal kunjungan terakhir.
  • Seluruh riwayat jasa servis dan mekanik yang pernah menanganinya.
  • Seluruh daftar sparepart yang pernah diganti pada kunjungan sebelumnya.

B. Fitur Simpan & Lanjut Keranjang (Pending Cart)

Jika transaksi menggantung (misal: motor pelanggan sedang dibongkar oleh mekanik dan transaksi belum selesai), gunakan tombol Simpan Keranjang (ikon disket) untuk menyimpan daftar belanja berdasarkan plat nomor kendaraan. Transaksi kasir bisa Anda lanjutkan nanti dengan masuk ke menu Keranjang Tersimpan.

4. Panduan Penanganan Masalah (Troubleshooting Kasir)

🔴 EROR: Server / Internet Terputus (Koneksi Error)
Penyebab: Koneksi WiFi lokal mati atau server backend crash.
Tindakan: 1. Coba refresh halaman dengan tombol Ctrl + F5.
2. Jika masih gagal, cek apakah server lokal menyala. Laporkan segera ke admin/pemilik untuk mengecek status PM2 node server di komputer utama.
3. Jangan menutup browser agar data keranjang aktif tidak hilang.
🔴 EROR: Salah Input Transaksi / Salah Bayar (Perlu Batalkan Transaksi)
Penyebab: Kasir salah memilih metode pembayaran atau salah memasukkan item barang namun transaksi telanjur disimpan.
Tindakan: 1. Masuk ke halaman Laporan dan temukan transaksi yang salah.
2. Klik tombol Hapus/Batalkan Transaksi. Sistem otomatis akan menghapus catatan keuangan dan mengembalikan jumlah stok barang secara otomatis ke database.
3. Buat transaksi baru yang benar di halaman Kasir.
🔴 EROR: Printer Struk Tidak Merespon
Penyebab: Printer offline, kehabisan kertas thermal, atau kabel USB terputus.
Tindakan: 1. Cek lampu indikator printer (jika merah berkedip, tandanya kertas habis).
2. Periksa colokan kabel USB ke komputer kasir.
3. Klik tombol Cetak Struk kembali setelah printer kembali online.
