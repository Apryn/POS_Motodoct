STANDARD OPERATING PROCEDURE (SOP) GUDANG

SOP Inventaris, Penataan Rak, & Impor Stok Excel
Divisi: Back Office / Gudang (Inventory)
Tanggal Berlaku: 14 Juni 2026
Jumlah Karyawan: 1 Admin Gudang
Tipe Dokumen: Panduan Operasional Resmi

1. Manajemen Penataan Barang & Rak

Setiap barang yang masuk wajib diletakkan pada lokasi rak yang sesuai dengan ketentuan bengkel.

  • Standardisasi Kode Rak: Pilihan lokasi rak standar adalah dari 1A sampai 12C.
    • Format penamaan rak: [Nomor Baris][Kode Kolom], contoh: 1A, 5B, 12C.
  • Input Barang Baru / Edit Modal: Ketika menambahkan sparepart baru, pilih lokasi rak menggunakan dropdown pada kolom Lokasi Rak.
  • Koreksi Data Rak Cepat (Inline Edit): Untuk merapikan data rak tanpa membuka menu Edit secara penuh, klik langsung tulisan lokasi rak pada tabel Stok Gudang, pilih opsi rak baru pada dropdown yang muncul, lalu tekan Enter atau klik di luar area untuk langsung menyimpan perubahan.
⚠️ PENTING: Penanganan Rak Non-Standar (Legacy)
Jika data barang lama di database menggunakan kode rak non-standar (misalnya RAK-BAN atau 12 x), sistem akan memunculkannya dengan warna merah dan bertuliskan (Non-standar). Segera lakukan penataan ulang fisik barang ke rak standar (1A-12C) dan ubah data rak tersebut melalui dropdown tabel.

2. Alur Impor Stok Excel (Pembelian Stok)

Apabila terdapat kedatangan barang dalam jumlah besar dari distributor, Anda dapat menggunakan modul Pembelian Stok via Excel.

Langkah 1: Unggah & Pemetaan Kolom

  1. Masuk ke halaman Pembelian Stok, klik tombol Pilih File Excel, lalu pilih dokumen Excel dari distributor.
  2. Petakan kolom Excel ke struktur data sistem (Kode Barang, Nama Barang, Stok Masuk, Harga Beli, Harga Jual, Merek, Unit Satuan, Tipe Motor).

Langkah 2: Verifikasi Perbandingan Data (Visual Preview)

Sistem akan menampilkan pop-up komparasi visual sebelum data dimasukkan ke database:

  • Pencocokan Kategori Cerdas: Sistem secara otomatis akan memetakan kategori barang baru yang mengandung kata "Ban" atau "Oli" ke kategori Ban dan Oli masing-masing secara otomatis.
  • Merge Tracking: Sistem akan melacak apakah barang tersebut sudah ada di gudang (berdasarkan kode/nama barang). Jika ada, sistem akan menampilkan data lama dan data baru secara bersandingan (harga lama vs harga baru, stok lama vs stok baru).
  • Koreksi Inline Preview: Jika ada kolom kode barang yang kosong atau salah pada layar preview, Anda dapat mengklik langsung sel kode barang tersebut di preview untuk mengeditnya secara manual sebelum diklik impor.

Langkah 3: Proses Akhir Impor

  • Setelah data diverifikasi dan sesuai, klik Impor Data. Sistem akan menampilkan progress bar pengunggahan. Tunggu hingga proses selesai 100%.

3. Fitur Kartu Stok (Mutasi Barang)

Apabila terdapat selisih stok fisik dengan data sistem, Anda dilarang langsung mengubah angka stok secara asal. Lakukan pelacakan melalui Kartu Stok:

  1. Pada tabel Stok Gudang, klik angka jumlah stok barang yang bergaris bawah oranye (misalnya: 10 pcs).
  2. Sistem akan membuka pop-up kronologis mutasi stok barang tersebut secara lengkap (pembelian, penjualan, retur, penyesuaian).
  3. Pastikan saldo mutasi terakhir cocok dengan stok fisik barang di rak.

4. Panduan Penanganan Masalah (Troubleshooting Gudang)

🔴 EROR: Salah Impor File Excel / Stok Berantakan Setelah Impor
Tindakan Segera: 1. Jika Anda menyadari data hasil impor salah, jangan panik. Pada halaman Pembelian Stok, klik tombol Undo Last Import (Batalkan Impor Terakhir).
2. Sistem akan menghapus seluruh data barang baru yang diimpor dari sesi terakhir tersebut dan mengembalikan stok lama ke kondisi semula secara instan.
3. Perbaiki file Excel Anda lalu ulangi langkah impor.
🔴 EROR: Kode Barang Duplikat atau Salah Normalisasi Unit
Tindakan Segera: 1. Jika sistem menolak impor karena kode barang duplikat, cari kode barang tersebut pada kolom pencarian Stok Gudang.
2. Jika terjadi kesalahan penamaan unit satuan (misal `klg` atau `sets`), sistem kasir secara otomatis mengoreksi menjadi `kaleng` dan `set`. Jika ada unit yang tidak biasa, lakukan edit barang dan ubah satuan melalui dropdown satuan resmi (pcs/set/botol/liter/pack/dus/kaleng).
